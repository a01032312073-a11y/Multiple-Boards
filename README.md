# 스마트 옵션 게시판 & 1인 1공감 토글 시스템

사용자 요구사항 및 스펙 이미지에 맞추어 구현된 현대적이고 반응형 웹 게시판입니다.

---

## 🌟 핵심 구현 기능

### ① 공개 범위 (이미지 스펙 ①)
- **전체 공개**: 모든 방문자가 글 목록과 본문을 자유롭게 열람할 수 있습니다.
- **비공개 (관리자만 열람)**: 
  - 일반 사용자가 볼 때 목록에 **`🔒 비공개 글입니다`**로만 마스킹되어 표시됩니다.
  - 비관리자가 클릭 시 본문 대신 관리자 비밀번호 인증 창이 뜹니다.
  - 우측 상단 **[👑 관리자 로그인]** (기본 비밀번호: `admin1234`) 인증 시 비공개 글의 원본 제목과 본문을 정상 열람할 수 있습니다.

### ② 수정 권한 (이미지 스펙 ②)
- **비밀번호로 수정·삭제 허용**: 
  - 글 작성 시 비밀번호를 설정하며, 글 상세 페이지에서 [수정] 또는 [삭제] 시 비밀번호를 확인합니다.
- **수정 불가 (잠금)**: 
  - **"잠금을 고른 글은 등록 후 누구도 고칠 수 없음"** 스펙에 따라 글 상세 화면의 수정 버튼이 잠금 상태(`🔒 수정 불가(잠금)`)로 고정되며 클릭 시 수정이 원천 차단됩니다.

### ③ 공감 허용 및 1인 1공감 토글 시스템 (이미지 스펙 ③ & 사용자 요청)
- **공감 허용**: 허용한 글에만 상세 화면 하단에 크고 직관적인 **👍 공감 버튼**이 표시됩니다.
- **공감 허용 안 함**: 공감 버튼이 아예 표시되지 않으며, 공감 비허용 안내가 제공됩니다.
- **1인 1공감 & 토글 취소 (요구사항)**:
  - **한 사람당 한 번만** 공감을 누를 수 있습니다.
  - 이미 공감을 누른 상태에서 한 번 더 누르면 **공감이 취소**되고 공감 수가 1 감소합니다.
  - 상단 헤더의 **`👤 접속자: [홍길동 | 김철수 | 이영희 | 박민수 | +새 닉네임 입력]`** 드롭다운을 통해 접속자를 즉시 변경하여, 1인 1공감 및 중복 방지 기능이 완벽하게 작동하는 것을 한 브라우저 안에서 편리하게 테스트할 수 있습니다.

---

## 🚀 실행 방법

### 방법 1: 브라우저에서 바로 열기 (가장 간편한 방법)
1. 폴더 내의 **`index.html`** 파일을 더블 클릭하여 크롬, 엣지 등 웹 브라우저로 엽니다.
2. 내장된 LocalStorage 데이터베이스 엔진을 통해 별도 서버 실행 없이도 모든 기능(글 작성, 수정, 삭제, 공감 토글, 비공개 마스킹, 사용자 전환)이 100% 정상 작동하며 데이터가 영구 보존됩니다.

### 방법 2: Node.js 로컬 서버로 실행하기
1. 터미널(PowerShell 또는 CMD)을 열고 현재 디렉터리로 이동합니다.
2. 아래 명령어를 실행합니다:
   ```bash
   node server.js
   ```
3. 웹 브라우저에서 **`http://localhost:3000`** 으로 접속합니다.
   - REST API와 `data/posts.json` 파일을 통해 게시글이 저장 및 동기화됩니다.
